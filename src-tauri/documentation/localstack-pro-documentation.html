LocalStack Pro Documentation

Windows local server, host manager, CMS installer and file manager.

Creator: Farid Leonov

v1.0.2
Русский

Быстрый старт

  1. Откройте Сервисы и нажмите Найти.
  2. Установите отсутствующие компоненты через Установить отсутствующие.
  3. Запустите Apache/MySQL/Node proxy, синхронизируйте hosts и откройте сайт.
English

Quick start

  1. Open Services and click Detect.
  2. Install missing components with Install Missing.
  3. Start Apache/MySQL/Node proxy, sync hosts and open the site.
Русский

Окно и ярлык

Приложение стартует развернутым на весь экран. Установщик создает ярлык LocalStack Pro.lnk на рабочем столе текущего пользователя и использует lime-иконку приложения.

English

Window and shortcut

The app starts maximized. The installer creates a LocalStack Pro.lnk desktop shortcut for the current user and uses the lime application icon.

Русский

Сервисы

Apache, Nginx, PHP, MySQL, MariaDB, PostgreSQL, Redis, Mailpit, Node.js Proxy и DNS Helper управляются через настоящий Rust backend. Статусы, PID, порты, ошибки и логи берутся из runtime, а не из макета.

English

Services

Apache, Nginx, PHP, MySQL, MariaDB, PostgreSQL, Redis, Mailpit, Node.js Proxy and DNS Helper are controlled by the Rust backend. Status, PID, ports, errors and logs come from runtime state.

Русский

Хосты

Хост хранит домен, root folder, document root, PHP-версию, web server, SSL, порты, БД, почту, env-переменные и заметки. Sync Hosts File добавляет домены в Windows hosts с повышением прав.

English

Hosts

A host stores domain, root folder, document root, PHP version, web server, SSL, ports, database, mail service, env variables and notes. Sync Hosts File updates the Windows hosts file with elevation.

Русский

CMS

WordPress, Joomla, Drupal, Grav, Meteor Blog CMS, Node/Next/Vite шаблоны и пользовательские PHP CMS устанавливаются в выбранную папку проекта. При включенной опции создается реальная база данных и записываются доступы.

English

CMS

WordPress, Joomla, Drupal, Grav, Meteor Blog CMS, Node/Next/Vite templates and custom PHP CMS projects install into the selected project folder. When enabled, LocalStack creates a real database and saves credentials.

Русский

Node.js / Next.js

  1. Проект должен иметь package.json.
  2. Для хоста укажите documentRoot=..
  3. Добавьте LOCALSTACK_NODE_PORT, LOCALSTACK_NODE_SCRIPT и LOCALSTACK_NODE_KIND.
  4. Запустите Apache и Node.js Proxy.
English

Node.js / Next.js

  1. The project must have package.json.
  2. Use documentRoot=. for the host.
  3. Add LOCALSTACK_NODE_PORT, LOCALSTACK_NODE_SCRIPT and LOCALSTACK_NODE_KIND.
  4. Start Apache and Node.js Proxy.
Русский

Базы данных

Создание, удаление, импорт, экспорт и backup выполняются через mysql/psql/mysqldump/pg_dump. Если клиент или сервис отсутствует, приложение показывает понятную ошибку и не создает фейковое состояние.

English

Database

Create, delete, import, export and backup actions use mysql/psql/mysqldump/pg_dump. If the client or service is missing, the app shows a clear error and does not create fake state.

Русский

SSL

Сертификаты создаются в AppData, SAN-домены сохраняются в состоянии. Trust/Repair Trust работает через Windows Certificate Store и может запросить права администратора.

English

SSL

Certificates are generated in AppData, SAN domains are stored in state. Trust/Repair Trust uses the Windows Certificate Store and may require administrator approval.

Русский

Файловый менеджер

Двухпанельный режим поддерживает создание, переименование, копирование, перемещение, chmod/ACL, загрузку файлов, архивы, поиск по содержимому и редактор кода с подсветкой синтаксиса.

English

File manager

The dual-pane manager supports create, rename, copy, move, chmod/ACL, upload, archives, content search and a code editor with syntax highlighting.

Русский

Настройки и темы

Язык, тема, плотность, автозапуск, трей, папки, порты, уведомления, backups и logs сохраняются локально. Тема Мокрый асфальт с lime-акцентом используется как основной визуальный режим.

English

Settings and themes

Language, theme, density, startup, tray, folders, ports, notifications, backups and logs are stored locally. The Wet Asphalt lime-accent theme is the main visual mode.

Русский

Диагностика

  • 503/502: проверьте Apache/Node proxy и логи хоста.
  • ERR_CERT_AUTHORITY_INVALID: выполните SSL Repair Trust.
  • Domain not mapped: нажмите Sync Hosts File.
  • MySQL access denied: проверьте сервис, native client и пароль пользователя.
English

Troubleshooting

  • 503/502: check Apache/Node proxy and host logs.
  • ERR_CERT_AUTHORITY_INVALID: run SSL Repair Trust.
  • Domain not mapped: click Sync Hosts File.
  • MySQL access denied: check the service, native client and user password.
